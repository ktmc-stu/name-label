Deployment

Setup in four steps 四步完成

1
Create stations 建立站點

In Remote → Stations, add a name + token per printer (e.g. LOBBY1 / LAB2).

2
Bind each printer 綁定列印端

Open parents-printer.html on the printer PC, enter its token, press Bind. It is remembered.

3
Import students 匯入學生

Excel columns: Card ID, Class, Class No, English Name, Chinese Name. Same card ID updates the record.

4
Select & swipe 選擇並刷卡

Pick the target station in Remote, then swipe — every label goes there until you switch.
