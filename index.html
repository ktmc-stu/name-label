Deployment

Setup in five steps五步完成

1
Create stations 建立站點

In Admin → Stations, add a name and token per printer (e.g. LOBBY1 / LAB2).

2
Bind each printer 綁定列印端

Open parents-printer.html on the printer PC, enter its token, press Bind. It is remembered.

3
Import students 匯入學生

Excel columns: Card ID, Class, Class No, English Name, Chinese Name. Same card ID updates the record.

4
Operate 操作

Swipe in Admin or Printer to auto-mark present and print, or use the handheld Remote to search and tap.

5
Review attendance 查看考勤

In Admin, filter by date and class, export Excel, and mark any unmarked students as absent.
