Deployment

Setup in five steps五步完成

1
Create stations 建立站點

In Admin → Stations, add a name and token per printer.

2
Bind each printer 綁定列印端

Open parents-printer.html on the printer PC, enter its token, press Bind.

3
Design the label 設計標籤

In Admin → Label Designer, drag text boxes and use {class}, {classNo}, {nameEn}, {nameZh}. Save once for all printers.

4
Import students 匯入學生

Excel columns: Card ID, Class, Class No, English Name, Chinese Name.

5
Operate & review 操作及考勤

Swipe or use Remote, then filter and export attendance in Admin.
